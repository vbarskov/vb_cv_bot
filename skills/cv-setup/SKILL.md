# Подключение cv_bot

VB CV Bot — адаптер к уже существующему проекту `cv_bot`. Он не содержит бот, конфиг соискателя, резюме, базу вакансий или браузерную сессию.

1. Вызови `cv_status`. Если подключение уже подходит запросу, используй его.
2. Для нового подключения получи путь к существующему проекту из запроса или доступного контекста. Вызови `cv_connect_workspace(workspace, config_path?)`; путь к конфигу нужен только при нестандартном расположении.
3. Проверь результат через `cv_status` и сообщи путь проекта, доступность конфига и базы. Отсутствие базы означает, что очередь ещё не наполнена. Не выдавай его за отсутствие вакансий на hh.ru. Этот инструмент не проверяет запуск Chrome, наличие Playwright или действительность сессии.

Сервер MCP работает на стандартной библиотеке Python 3. Браузерные команды и скоринг используют Python и зависимости исходного проекта. Если их не хватает, покажи конкретную отсутствующую зависимость и инструкции из README проекта; установка пакетов, Chrome и вход в аккаунт не являются частью подключения.

`VB_CV_BOT_HOME` задаёт каталог состояния адаптера; по умолчанию это `~/.local/share/vb-cv-bot`. `VB_CV_BOT_WORKSPACE` может задать исходное рабочее пространство. Не копируй конфиг, резюме, cookies, базу и debug-файлы внутрь плагина и не заменяй исходные данные демонстрационными.

Для очереди и писем используй `$cv-queue`; для подготовки поиска или откликов — `$cv-run`. Подключение не разрешает открывать браузер или отправлять отклики.
